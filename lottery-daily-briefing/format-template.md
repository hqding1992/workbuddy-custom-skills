# 简报格式模板

> 本文件定义彩票新闻简报的标准输出格式。生成简报时严格按照此模板填充内容，确保每次简报风格统一、信息完整。
>
> ⚠️ **与 `_audit.js` 对齐（2026-08-05 固化）**：本模板使用**散文体**——条目用 `N. **标题**` 编号+加粗，内容写通顺叙述，来源/URL 单独成行。**严禁使用 `### 条目标题` 与 `- **子字段**` 写法**：审计脚本会把每个 `### ` / `- **` 当成独立条目建项，导致空正文/跨节重复误报（issues/dups 爆表），简报被卡死无法分发。

---

## 📁 文件规范

| 项目 | 规范 |
|------|------|
| **文件名** | `今日彩票新闻简报_YYYYMMDD.md` |
| **文件编码** | UTF-8 |
| **保存路径** | `{workspace}/`（当前工作区根目录） |
| **时间标注** | 标题下方必须标注：`**（YYYY年MM月DD日12:00至YYYY年MM月DD日12:00）**` |

## 📏 格式注意事项

| 项目 | 规范 |
|------|------|
| **条目层级** | 用 `N. **标题**` 编号+加粗标记条目。**严禁 `### 条目标题` 与 `- **子字段**`**（审计会误判为独立条目） |
| **内容写法** | 写通顺叙述。字段信息（时间/地点/主办/来源/参与）融入叙述，或置于条目末尾的轻量元信息行（`时间：X｜地点：Y｜主办：Z｜参与：W`），**不逐条堆 `- **字段**`** |
| **来源标注** | 政策动态：来源名称（原文URL）；活动/渠道/中奖：来源名称（发布日期），不展示 URL |
| **公众号来源** | 格式为"XX省/市体彩/福彩微信公众号（YYYY年MM月DD日发布）" |
| **时间格式** | 统一"YYYY年MM月DD日" |
| **金额格式** | 使用中文单位（万元/亿元），数字用阿拉伯数字 |
| **表格** | 仅用于"最新开奖"汇总表与"开奖预告"表 |
| **分隔线** | 各大类之间用 `---` 分隔，并保持一个空行 |
| **空行** | 标题行与叙述段之间空一行；叙述段与元信息行之间不强制空行 |

## 🧹 成品去噪规则（生成/转换强制，2026-08-05 固化）

简报成品**只含读者内容**。以下内部注记/标签属于构建过程产物，**必须剔除，不得进入读者简报**（仅留构建日志备查）：

- **政策剔除说明**：形如 `（注：…按强清洗规则予以剔除…）` 的整段内部说明；
- **内部标签**：`(江苏本地重点关注)`、`(本地重点关注)`、`(特别关注)` 等运营标记；
- **数据校正括号**：`(…补发，原题…)`、`(综合转述…)`、`(原文…)` 等数据溯源注记（如确属必要来源说明，简化为干净的"来源：XX（日期）"即可）。

> 注：此规则是 2026-07-28 强清洗规则的延伸——此前只管"网页垃圾正文/历史归档冒充新政"，未约束生成阶段漏注。凡进入 `_audit.js` 前的成品，均不得含有上述内部注记。
